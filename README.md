# Atharva Navlekar - Portfolio 🚀

Welcome to the personal portfolio repository of **Atharva Navlekar**, a creative Java Developer and Business Analyst based in Mumbai. This portfolio showcases my skills, experience, and key projects, highlighting my expertise in merging technical development with business strategy.

## 🌟 Overview

This responsive website serves as a digital resume and showcase platform. It features smooth scrolling, modern typography, and engaging animations to provide an immersive user experience.

**Live Demo:** [https://thenavlekar.netlify.app/](https://thenavlekar.netlify.app/)

## ✨ Features

-   **Modern UI/UX:** Clean, dark-themed design with vibrant accents.
-   **Smooth Scrolling:** Implemented using **Locomotive Scroll** for a fluid navigation experience.
-   **Animations:** Powered by **GSAP (GreenSock Animation Platform)** and **ScrollTrigger** for dynamic content reveal and effects.
-   **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.
-   **Structured Sections:**
    -   **Introduction:** Engaging hero section with animated text.
    -   **About:** Personal introduction and professional summary.
    -   **Skills/Expertise:** Highlighting core competencies in Java, Business Development, and SEO.
    -   **Experience & Education:** Detailed timelines of professional and academic journey.
    -   **Featured Projects:** Showcasing top works like "Lecture Manager" and "Movie Recommendation System".
    -   **Contact:** Social links and email for connection.

## 🛠️ Tech Stack

-   **HTML5:** Semantic markup for structure and SEO.
-   **CSS3:** Custom styling for layout and aesthetics.
-   **JavaScript (ES6+):** Logic for interactivity and DOM manipulation.
-   **Libraries:**
    -   [Locomotive Scroll](https://github.com/locomotivemtl/locomotive-scroll) - For smooth scrolling effects.
    -   [GSAP](https://greensock.com/gsap/) - For high-performance animations.
    -   [ScrollTrigger](https://greensock.com/scrolltrigger/) - For scroll-based animations.

## 🚀 Getting Started

To run this project locally on your machine:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/atharvanavlekar/portfolio.git
    ```
    *(Or download the ZIP file and extract it)*

2.  **Navigate to the project directory:**
    ```bash
    cd portfolio
    ```

3.  **Open `index.html`:**
    Simply double-click `index.html` to open it in your preferred web browser. Alternatively, use a live server extension (like Live Server in VS Code) for a better development experience.
